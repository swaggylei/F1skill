# Statistical definitions / 统计口径

Default scope is championship Grand Prix races from 1950 onward, with explicit disclosure for Indianapolis 500 (1950–1960), championship races run under Formula 2 regulations, and non-championship exclusions. Never silently switch the historical population to match a preferred source.

| Concept | Required distinction |
|---|---|
| Entry / start / finish | Entry is not a start; DNS, DNQ, DNF, DSQ and classified non-finisher are distinct. Use official status and define finish vs classification. |
| Qualifying / pole / grid | Fastest qualifying result, officially credited pole and actual starting position may differ. Follow the applicable year's official convention; include Sprint-era exceptions explicitly. |
| GP / Sprint | Separate counts, wins, podiums, points and starts. Combined totals require a named combined definition. |
| Fastest lap | Race fastest lap, fastest personal lap, lap record, qualifying lap and points eligibility are different. Check the season's rules; do not assume a fastest-lap point exists. |
| Points | Actual awarded points, adjusted points and hypothetical normalized points are separate. Account for dropped scores, shared drives and shortened races where relevant. |
| Driver / team | Use stable driver IDs. Constructor, entrant, commercial team name, chassis and engine supplier are separate identities. State whether renamed teams share lineage. |
| Streak | Define event order and reset condition. Consecutive calendar races include absence as a break unless definition says consecutive starts. DNS, cancellation and disqualification treatment must be explicit. |
| Gap / duration | Days vs elapsed seconds vs intervening races; use consistent precision and verified dates. Do not invent finer precision than a source supports. |
| Win margin | Final official classification/time after penalties; lapped finishers and interrupted races need explicit handling. |
| Age | Date-of-birth to event date in stated timezone; express days or years/days consistently. |
| Ties / ranks | Preserve equal records and joint holders. Declare ranking method and handling of timing precision. |

Changes in rules, race count, circuit layouts, timing methods and reliability limit cross-era comparability. Identify limits; do not apply modern rules retroactively. Flag missing lap-by-lap, grid or historical qualifying data before using them for universal claims.
